Caixa

Vendas e fluxo de caixa

Caixa Fechado

Abra o caixa informando o valor inicial em dinheiro (fundo de troco)
para começar a registrar vendas.

Dica: O fundo de troco é usado para dar troco aos clientes nas vendas.

Terminal do Caixa

💡 Dica: aperte a letra do comando (P, Q, D, E, I, T, A, N, O, H, F) pra abrir a janela correspondente. As letras não aparecem digitadas — digite um número antes pra usar como quantidade/item/valor (ex: 5 + P, 2 + D).

Atalhos do Terminal

PProdutoAbre busca de produto (Nº = qtd.)
QQuantidadeAbre janela pra definir a quantidade
EEditar QuantidadeAbre lista de itens pra editar
DDeletar ItemAbre lista de itens pra excluir
CCancelar CompraAbre confirmação e cancela a venda
IDesconto ItemAbre lista de itens pra dar desconto
TDesconto TotalAbre janela de desconto (R$/%)
AAcréscimoAbre janela de acréscimo (R$/%)
NCPF/CNPJAbre janela pra adicionar CPF/CNPJ
OObservaçãoAbre janela de observação
HHistóricoAbre o histórico de vendas
LLimpar TerminalLimpa o texto do terminal
FFinalizar VendaFinaliza a venda atual

Letra = ação instantânea · Número antes = quantidade/item/valor · ↑↓ navegam · Esc cancela · O terminal permanece sempre focado
